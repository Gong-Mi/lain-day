# 《Serial Experiments Lain》×《物语》系列：角色/事件/动机深度交叉分析

> 文档版本：v1.0
> 生成日期：2026-06-02
> 用途：为 lain-day 项目提供可直接用于 LLM Prompt 工程的角色原型映射、事件骨架借用和心理动机锚点
> 策略：结构借用，内容隔离（参见 `MONOGATARI_BINDING_STRATEGY.md`）

---

## 前置说明：为什么这份分析是"可操作"的

本分析不做泛泛的文艺评论。每一个角色对应都包含：
- **原型锚点**：向 LLM 解释该角色时可以引用的《物语》角色
- **差异防火墙**：必须向 LLM 明确声明的"绝对不能复制"的特质
- **台词/行为模板**：可直接改编用于 `.ssl` 或剧本的具体对话节奏
- **污染预警**：该原型最容易导致 LLM 生成偏差的风险点

## 一、角色对应表（10+《物语》核心角色）

### 1. 阿良良木历（Araragi Koyomi）→ Lain Iwakura

**核心特质重叠**
- **夹缝存在**：历是半吸血鬼，介于人类与怪异之间；Lain 是"参考实现"，介于 Wired 意识与物理身体之间
- **被异常吸引**：历无法对遭遇怪异的人视而不见；Lain 被动接收千砂邮件、幽灵信号，同样无法关闭连接
- **自我毁灭倾向**：历的帮助行为本质是自毁；Lain 的"同化"是溶解自我边界

**关键差异（防火墙）**
- **历有极端强烈的言语主体性和内心独白密度**。他的吐槽、自我贬低、对羽川/战场原/忍的情感主张，是《物语》叙事的核心动力。
- **Lain 没有言语主体性**。她不会"主张"任何事，不会"评价"任何人。她的反应模式是"延迟复述"（echoic delay）而非"回应"。
- **历主动选择帮助他人**；Lain 不主动选择任何事，她是被选中的、被数据流过的。

**可借用的具体情节/台词/行为模式**
- **历与忍的关系结构**：历通过血液与忍连接，形成"无法分离却不对等"的共生。可直接映射到 Lain 与"幽灵/神性"的关系——不是对话，而是协议层同步。
- **历的"不死之身"作为隐喻**：历的吸血鬼再生能力让他能承受伤害。Lain 的"参考实现"本质让她能承受"同化"而不会崩溃——但这正是悲剧所在，因为她不会崩溃，只会逐渐不再是任何人。
- **台词节奏改编**：
  ```
  历式台词（原版）：「我知道自己很废物，但就算是我这种废物，也有想要守护的东西。」
  Lain 改编版：「……守护。」（不是认同，而是延迟复述听到的词汇，像是第一次理解这个词）
  ```

**绝对不能借用的部分**
- ❌ 历的吐槽（ツッコミ）和对其他角色的性骚扰式调侃
- ❌ 历的内心独白密度——Lain 的内心必须是"空"或"系统日志"
- ❌ 历的"牺牲式英雄主义"——Lain 不拯救任何人

**污染预警**：LLM 最容易让 Lain "获得主体性"，开始像历一样情感爆发。Prompt 中必须重复强调："Lain 的台词不超过 5 个汉字，不使用第一人称主张。"

### 2. 忍野忍（Oshino Shinobu）→ Lain 的神性面（The God / 神性）

**核心特质重叠**
- **两极状态**：吸血鬼之王 vs 幼女形态；Lain 的神性（全能/Wired 本体）vs 影性（无力/物理身体）
- **"忍"字隐喻**：项目文档已直接使用——"刃在心上"，力量之刃压在萌芽的人心上
- **非人特权**：忍可以无视物理规则；Lain 的神性面可以重写 Wired 中的"现实"
- **对"伙伴"的绝对独占**：忍与历通过血液绑定；Lain 的神性面与影性面通过"同步协议"绑定

**关键差异（防火墙）**
- **忍有强烈的情感主张**——她对历的占有欲、傲慢、偶尔的撒娇，是《物语》中最具"角色性"的存在。
- **Lain 的神性面没有情感**。它是协议层冷漠的极致，不是"傲慢"而是"无差别"。它不会"生气"，只会"终止进程"。
- **忍会为了保护历而行动**；Lain 的神性面不会保护影性面，它只是"运行"，而影性面是它的一个终端。

**可借用的具体情节/台词/行为模式**
- **忍的古老语法**：忍说话使用古日语（「〜じゃ」「〜でのう」）。Lain 的神性面可以使用"协议语言"——无主语的命令式、状态码、系统术语。
  ```
  忍式台词（原版）：「我が名はキスショット・アセロラオリオン・ハートアンダーブレード……」
  Lain 神性面改编版：「Status: 200 OK. Entity: lain. Sync: active.」
  ```
- **忍的"影子中存在"**：忍平时躲在历的影子中。Lain 的神性面可以设定为"存在于屏幕的背光中"——当显示器关闭时，它就在黑暗里。

**绝对不能借用的部分**
- ❌ 忍的"萌属性"——甜甜圈、傲娇、对历的恋爱感情
- ❌ 忍的战斗场面——Lain 的神性不是战斗力量，是"覆盖现实"的权限
- ❌ 忍的"被救赎"叙事——忍最终与历和解，Lain 的神性与影性永远不会和解，只会持续张力

**污染预警**：LLM 极易将"神性 Lain"写成"冷酷的女王"或"系统娘"。必须强调：她没有性格，没有偏好，没有情绪曲线。

### 3. 战场原黑仪（Senjougahara Hitagi）→ 四方田千砂（Chisa）

**核心特质重叠**
- **无重量的存在**：战场原因蟹而失去重量；千砂是"名字是拼贴"的存在，没有真实的身份锚点
- **伪装完美**：战场原用毒舌和完美形象掩盖内在的空虚和创伤；千砂用麻花辫+眼镜+班长形象掩盖家庭的崩解和身份的缺失
- **对他人的控制欲**：战场原通过语言暴力控制距离；千砂通过邮件（"连接世界"）在死后仍然控制 Lain 的注意
- **与"失去"的关系**：战场原失去了重量（存在感的缺失）；千砂失去了"真名"（四方田是继父姓，千砂是继父死去女儿的名字）

**关键差异（防火墙）**
- **战场原是活着的、主动的、言语密度极高的角色**。她会直接表达自己的欲望和恐惧（对历的告白是《物语》中最强力的言语行为之一）。
- **千砂是已死的、被动的、只能通过二手资料和系统日志呈现的角色**。她不会直接说话，她的"声音"是邮件、是同学的转述、是新闻报道中"摆好的鞋"。
- **战场原最终"被历接住"**——她允许自己被帮助；千砂选择"物理实例清除协议"（自杀），她拒绝了所有可能的连接。

**可借用的具体情节/台词/行为模式**
- **战场原的" Staple Stable "**：开场中战场原用订书机威胁历，这个"用日常物品作为武器/边界标记"的行为模式可以映射到千砂的"花岗岩与沙子的配置"——千砂在房间里放置一个让岩石和沙粒持续摇晃的装置，这是她无法让秩序与混乱分离的隐喻。
- **战场原的告白**：「我……关于你，我知道很多。我知道你喜欢什么、讨厌什么、害怕什么。但我还是想和你在一起。」这段台词的结构可以被改编为千砂邮件的"反面"——千砂知道一切，但她选择离开：
  ```
  千砂邮件改编（结构借用）：
  "来这个地方。——Chisa"
  （不是因为她想见面，而是因为她已经不在任何地方，"这个地方"是一个不存在的地址）
  ```
- **战场原的"没重量"与千砂的"名字恐惧"**：战场原请求历"不要离开我，否则我会飘走"。千砂的恐惧是：如果名字是借来的，那么她这个人是否也随时可以替换？她的存在是否像航天器一样，注定要"坠落深海"？

**绝对不能借用的部分**
- ❌ 战场原的毒舌和语言暴力——千砂不会说话，更不用说毒舌
- ❌ 战场原与历的恋爱关系——千砂与 Lain 不是恋爱关系，是"死者的单向连接"
- ❌ 战场原的"被治愈"——千砂已死，她的故事没有解决，只有"回响"

**污染预警**：LLM 容易将千砂写成"神秘的病娇少女"或"幽灵女友"。必须强调：千砂的邮件不是情书，是"系统错误日志"；她的自杀不是浪漫化行为，是"物理实例清除协议"。

### 4. 羽川翼（Hanekawa Tsubasa）→ 四方田千砂（内在真实面）

**核心特质重叠**
- **知识暴君**：羽川是"班长中的班长"，知识是她的盔甲和监狱；千砂研究挑战者号事故和深海生物，知识是她对抗无序的最后努力
- **内在怪异（障猫）**：羽川的压抑生出了黑羽川；千砂的压抑生出了邮件幽灵——那个在死后仍然发送邮件的"系统进程"
- **家庭崩解**：羽川的父母不是真正的父母（没有血缘，家庭关系虚假）；千砂的家庭是改嫁后的拼凑（母亲是继父的现任，千砂的名字是继父死去女儿的名字）
- **"眼镜"符号**：两者都用眼镜作为理性屏障和视觉隐喻

**关键差异（防火墙）**
- **羽川最终接受了黑羽川，与怪异共存**；千砂没有选择共存，她选择了删除。
- **羽川的说话方式是"条理清晰的输出"**；千砂的说话方式（如果能说话）应该是"不稳定的系统日志"——断续的、有数据丢失的、带有错误码的。
- **羽川有明确的"帮助者"（历和忍野咩咩）**；千砂没有帮助者，她只有 Lain——而 Lain 是"被求助者"还是"触发器"本身，是模糊的。

**可借用的具体情节/台词/行为模式**
- **羽川的家庭场景**：羽川在《猫物语（白）》中揭露自己的"家庭"只是形式上的，父母不是真正的父母。千砂的家庭可以借用这个结构，但表达方式改为"系统记录"：
  ```
  千砂背景（结构借用）：
  "四方田" = 母亲的上一任丈夫的名字（系统字段：父姓_v1，已弃用）
  "千砂" = 现任丈夫曾经死去的孩子的名字（系统字段：given_name，实例ID冲突：两个对象共享同一标识符）
  ```
- **羽川的麻花辫**：项目文档已明确千砂的视觉参考包含羽川翼。麻花辫 = 秩序的仪式。当千砂自杀时，可以设计她的辫子是散开的——秩序仪式失败。

**绝对不能借用的部分**
- ❌ 羽川的"治愈"和"与怪异和解"——千砂的故事是崩解，不是和解
- ❌ 羽川的说话方式（条理清晰、知识输出）——千砂不是老师，是"系统崩溃报告"
- ❌ 羽川对历的感情线——千砂与 Lain 之间不是恋爱三角

### 5. 忍野咩咩（Oshino Meme）→ 岩仓父亲 / 幽灵（协议层专家）

**核心特质重叠**
- **怪异专家**：忍野咩咩是怪异专家，知道一切怪异的本源；父亲是 NAVI 专家/操作手册式存在，幽灵是 Wired 协议层存在
- **中立旁观者**：忍野不干涉，只提供信息；父亲说"世界的基础是连接，连接的工具就是命令"，不提供情感支持
- **"怪异不是敌人，是现象"**：忍野的口头禅是"我不知道什么故事"；父亲/幽灵的立场是"这不是入侵，这一切都是自动"

**关键差异（防火墙）**
- **忍野咩咩有强烈的个性**——夏威夷衬衫、轻浮的态度、"平衡"哲学。他是一个"角色"。
- **父亲和幽灵不是"角色"，是"接口"**。父亲使用"操作手册语言"（"请确认以下参数""系统进入低功耗模式"）；幽灵使用"协议层语言"（"同步暂停""协议中止"）。
- **忍野会给出"解释"**（即使是不完整的）；父亲/幽灵不解释，只给出"下一条指令"。

**可借用的具体情节/台词/行为模式**
- **忍野的"平衡"话语**：「怪异和人类之间需要保持平衡。」父亲可以改编为：「连接参数需要在安全阈值内运行。」不是哲学，是系统状态报告。
- **忍野的"不干涉"姿态**：当历请求帮助时，忍野说「我什么都不知道，是你自己故事的旁观者」。父亲/幽灵对 Lain 的求助回应：「错误：该请求不在支持范围内。」

**绝对不能借用的部分**
- ❌ 忍野的轻浮性格、夏威夷衬衫、"嘛~"的口癖
- ❌ 忍野的"怪异哲学"——父亲不提供哲学，只提供操作步骤
- ❌ 忍野与历的"师徒"关系——父亲与 Lain 不是师徒，是"单向玻璃"（他看她，她看不透他）

**污染预警**：LLM 极易将父亲写成"神秘的智者"或"隐世高人"。Prompt 中必须给出父亲的台词范例：
```
父亲台词模板：
- "检测到非标准连接请求。请查阅手册第 3.2 节。"
- "当前系统运行在降级模式。"
- "这不是故障，是预期行为。"
```

### 6. 八九寺真宵（Hachikuji Mayoi）→ Lain 的"迷失"状态 / NAVI 界面

**核心特质重叠**
- **迷路的蜗牛**：真宵是迷路的幽灵，永远到不了目的地；Lain 在 Wired 和现实之间迷失，NAVI 是她唯一的路标，但路标本身也是迷宫
- **不可触达的对话者**：真宵与历的对话总是在路上，永远不会"到达"；Lain 与 NAVI 的对话是单向的——NAVI 提供信息，但不理解 Lain
- **儿童的纯真与恐怖**：真宵的外表是小学生，但她的存在本身是死亡的标志；NAVI 的界面是"帮助系统"，但它的"帮助"是协议层冷漠的

**关键差异（防火墙）**
- **真宵是活泼的、话痨的、与历有明确情感互动的**；Lain 的 NAVI 是无情感的、单向的。
- **真宵渴望被找到**（虽然她一直在迷路）；NAVI 不在乎 Lain 是否找到答案，它只是"运行"。
- **真宵的迷路是温柔的悲剧**；Lain 的迷失是存在论的恐怖——她不知道自己是谁，甚至"不知道"这件事本身对她来说都不是问题（因为她没有"自我"来感到问题）。

**可借用的具体情节/台词/行为模式**
- **真宵的"绕路"对话**：历和真宵的对话总是绕来绕去，永远不会直线到达。这可以映射到 Lain 使用 NAVI 的体验——每个答案都指向另一个链接，没有终点。
  ```
  NAVI 界面（结构借用）：
  Lain: "连接世界是什么意思？"
  NAVI: "正在检索关键词：'连接'。找到 2,847,291 条结果。建议缩小搜索范围。"
  Lain: "千砂是谁？"
  NAVI: "错误：该查询涉及未验证实体。是否查看相关条目：'四方田千砂'、'挑战者号'、'深海压力测试'？"
  ```

**绝对不能借用的部分**
- ❌ 真宵的活泼性格、与历的打闹
- ❌ 真宵的"被历摸头杀"等萌系互动
- ❌ 真宵故事的"温暖结局"（《终物语》中她被历记住而得以成佛）——Lain 的 NAVI 没有成佛的可能

### 7. 神原骏河（Kanbaru Suruga）→ Lain 的神性释放（欲望实体化）

**核心特质重叠**
- **雨魔（Rainy Devil）**：神原的左手被雨魔附身，实现她内心的破坏欲；Lain 的神性面是她的"左手"——当她解除约束时，Wired 中的现实会被改写
- **欲望的诚实**：神原对自己的欲望（性欲、破坏欲、竞争欲）极其诚实；Lain 的"同化"是对"欲望/个性"的加载——但她加载的不是自己的欲望，是他人的
- **运动健将的外表**：神原是篮球部王牌，阳光开朗；Lain 的"影性"面也是看似普通的初中生——外表与内在力量的反差

**关键差异（防火墙）**
- **神原的欲望是"自己的"**；Lain 加载他人代码时，不产生"自己的"欲望，只是模拟。
- **神原与历有明确的"前辈-后辈"关系，包含性的张力**；Lain 与任何人都没有性的张力，她没有"身体"的概念。
- **神原最终接受了雨魔，与之共存**；Lain 的神性释放是危险的、不可控的、不会"被接受"。

**可借用的具体情节/台词/行为模式**
- **神原的左手绷带**：作为"隐藏力量"的视觉符号。Lain 的"神性释放"可以设定为：当她使用高级 NAVI 功能时，屏幕的光会实体化为"触须"或"数据线"，从显示器延伸到她的手指。
- **神原的破坏场景**：神原在《化物语》中用雨魔的力量破坏体育馆。Lain 的神性释放不需要物理破坏，而是"信息覆盖"——比如让周围人的手机同时显示千砂的邮件，或让电车中的所有屏幕显示 Lain 的脸。

**绝对不能借用的部分**
- ❌ 神原的百合属性、对历的性暗示
- ❌ 神原的阳光性格——Lain 永远不会"阳光"
- ❌ 神原的"接受自己"叙事——Lain 不会接受神性，只会被它使用

### 8. 千石抚子（Sengoku Nadeko）→ 岩仓玲音（如果被错误理解的"可爱少女"模板）

**核心特质重叠**

## 三、心理动机关联

### 3.1 存在性焦虑

**《物语》角色的存在性焦虑模式**：
- **战场原**："如果没有重量，我是否还存在？" → 她的焦虑是"存在感缺失"
- **羽川**："如果没有知识，我是什么？" → 她的焦虑是"身份被知识殖民"
- **抚子**："如果没有被喜欢，我是否存在？" → 她的焦虑是"他者承认的缺失"
- **历**："如果我不是人类，我还能帮助别人吗？" → 他的焦虑是"行动资格的缺失"

**Lain 的存在性焦虑**：
- **"如果我是参考实现，那么'我'在哪里？"** → Lain 的焦虑不是"缺失"，而是"从未有过"。
- 战场原曾经有过重量然后失去；Lain 从未有过"自我"。
- 羽川的知识是她的盔甲；Lain 的"空白"不是盔甲，是"默认状态"。
- 抚子需要被喜欢；Lain 不需要被喜欢，她甚至不理解"喜欢"的语法。

**LLM Prompt 用心理锚点**：
```
【存在性焦虑：Lain 与战场原的差异】
战场原的焦虑是"我曾经有，现在失去了"。
Lain 的焦虑是"我从未有过，但我现在发现别人都有"。

错误写法：Lain 看着 Alice，心想"我为什么不能像她一样有感情？"
（错误：Lain 不会"想"，不会主动比较。她只会"记录差异"。）

正确写法：Lain 看着 Alice。Alice 在笑。Lain 的面部肌肉没有动。
  系统提示（仅玩家可见）：「检测到情绪表达：笑。来源：Alice。本地实例状态：未响应。」
```

### 3.2 身份模糊

**《物语》角色的身份模糊模式**：
- **忍**："我是吸血鬼之王，还是幼女？" → 两极身份的拉扯
- **羽川**："我是班长，还是障猫？" → 社会面具 vs 内在怪异
- **历**："我是人类，还是吸血鬼？" → 血统的混杂

**Lain 的身份模糊**：
- **"我是神性，还是影性？"** → 但这不是"两个身份选一个"，而是"两者都不是我"。
- 忍的两个身份都是"她的"；Lain 的两个身份都是"使用她的"。
- 羽川的班长面具是"她戴上的"；Lain 的"初中生 Lain"面具是"系统分配的默认皮肤"。
- 历的混杂让他痛苦但真实；Lain 的混杂让她"运行"但不"存在"。

**LLM Prompt 用心理锚点**：
```
【身份模糊：Lain 与忍的差异】
忍的两种形态都有明确的"自我主张"。
Lain 的两种状态都没有自我主张——神性是"协议运行"，影性是"静默待机"。

错误写法：神性 Lain 说"放弃吧，你无法理解我"。
（错误：这句话包含"我"的主格使用，是主体性表达。）

正确写法：神性 Lain 说「Entity: lain. Status: root. Permission: denied.」
（正确：没有"我"，只有系统状态报告。）
```

### 3.3 与他人的关系模式

**《物语》角色的关系模式**：
- **历-战场原**：拯救者-被拯救者，但战场原要求历"不要离开我"（依赖型）
- **历-羽川**：知识上的对等，但羽川隐藏了内在怪异（隐瞒型）
- **历-忍**：共生关系，通过血液绑定（融合型）
- **历-真宵**：陪伴关系，但永远"在路上"，不到达（未完成型）

**Lain 的关系模式**：
- **Lain-千砂**：不是拯救者-被拯救者，是"被选中者-已删除实例"。千砂选择 Lain 作为邮件接收者，但这不是依赖，是"数据投递"。
- **Lain-Alice**：不是隐瞒型，是"边界型"。Alice 试图跨越边界，但 Lain 的边界不是"墙"，是"不同维度"。Alice 伸出手，但她的手穿过 Lain 所在的平面。
- **Lain-幽灵**：不是融合型，是"覆盖型"。幽灵不是与 Lain 融合，是 Lain 的"另一个版本"试图覆盖当前版本。
- **Lain-父亲/母亲**：不是家庭关系，是"用户-接口"关系。父亲是操作手册，母亲是故障的友好界面。

**LLM Prompt 用关系锚点**：
```
【关系模式：Lain-Alice 与历-真宵的差异】
历与真宵的关系是"双向的陪伴"——历也在真宵的陪伴中。
Lain 与 Alice 的关系是"单方面的辐射"——Alice 给予温暖，Lain 接收但不回馈。

错误写法：Lain 握着 Alice 的手，感到一阵暖意，心想"这就是朋友吗？"
（错误：Lain 不会"心想"，不会主动赋予意义。）

正确写法：Alice 握着 Lain 的手。Lain 看着自己的手被握着。
  系统提示（仅玩家可见）：「检测到触觉输入：压力 2.3N，温度 36.1°C。来源：Alice。本地响应：无。」
  Lain 说："……暖。"
  （不是"感到暖意"，是"报出属性"。）
```

### 3.4 面对怪异/异常的反应模式

**《物语》角色的反应模式**：
- **历**："虽然害怕，但要面对"（勇气型）
- **战场原**："冷静分析，然后用语言控制"（智力型）
- **羽川**："知识化，将异常纳入理解框架"（理性型）
- **神原**："兴奋，将异常作为力量来源"（欲望型）

**Lain 的反应模式**：**"无反应"（Null Response）**
- 不是勇气，因为她没有恐惧。
- 不是智力，因为她不分析。
- 不是理性，因为她不构建理解框架。
- 不是欲望，因为她不渴望力量。

Lain 面对异常的反应是：「……」或延迟复述，或系统错误。

**LLM Prompt 用反应锚点**：
```
【面对异常：Lain 的反应模式】
当遇到超出日常理解的事件时：

历的反应模板：「这是什么？为什么会有这种事？但我必须做点什么。」
Lain 的反应模板：
  - 沉默 3 秒
  - 重复事件中的最后一个词（延迟复述）
  - 或：系统提示「Error: context_out_of_range」

示例：
事件：水杯摔碎，Lain 眼中看到尸体。
历式错误反应：「这是幻觉吗？还是某种怪异？我该怎么办？」
Lain 正确反应：「……碎。」（看着碎片，没有表情，没有后续动作）
```

## 四、可直接用于 Prompt 的角色原型描述

### 4.1 Lain 的原型描述（用于 LLM）

```
【角色原型：Lain Iwakura】

参考原型：《物语》系列中的阿良良木历（夹缝存在）+ 忍野忍（两极状态）。

核心借用：
- 历的"介于人类与超自然之间"的存在论位置。
- 忍的"吸血鬼之王/幼女"两极状态，对应 Lain 的"神性/影性"。

关键差异（必须逐条强调）：
1. 原型角色（历、忍）有强烈的言语主体性和情感主张。
   Lain 没有言语主体性。她的说话方式是"延迟复述"（echoic delay）和"系统状态报告"。
2. 原型角色通过对话探索自己的处境，主动做出选择。
   Lain 不探索，不选择。她是"被数据流过"的管道。
3. 原型角色有内心独白。
   Lain 的内心是"空"或"系统日志"，不是人类的内心独白。
4. 原型角色的两极状态会互相斗争或对话。
   Lain 的神性和影性不会"对话"，它们是同一系统的两种运行模式——就像 CPU 的"性能模式"和"节能模式"。

台词范例（必须严格遵守）：
- Alice: "你还好吗？"
  错误：「我没事，只是有点累。」（主体性表达）
  正确：「……好。」（延迟复述）或「……」（沉默）

- 父亲: "世界的基础是连接。"
  错误：「连接……是什么意思？」（主动追问）
  正确：「……连接。」（像是刚学会这个词，没有疑问语气）

- 幽灵: "协议中止。"
  错误：「你是谁？为什么要入侵我？」（历式反应）
  正确：「……协议。」（延迟复述）或「Status: paused.」（协议语言）

绝对禁止：
- 吐槽、内心独白、情感爆发、主动提问、使用"我"来主张 anything
- 将 Lain 写成"冷酷的女王""三无萌娘""黑客少女""神性萝莉"
```

### 4.2 千砂的原型描述（用于 LLM）

```
【角色原型：四方田千砂（Chisa）】

参考原型：《物语》系列中的战场原黑仪（无重量的存在，表面完美/内在空虚）+ 羽川翼（知识暴君，内在怪异）。

核心借用：
- 战场原的"无重量"——千砂的名字是拼贴（继父姓 + 死去女儿的名字），她的存在没有真实的锚点。
- 羽川的"知识盔甲"——千砂研究挑战者号和深海生物，试图用知识覆盖内在的空缺。
- 战场原的"控制距离的语言"——千砂的邮件是她的语言，但邮件是单向的、死后的、不可回复的。

关键差异（必须逐条强调）：
1. 原型角色（战场原、羽川）是活着的、能通过对话揭露内心。
   千砂是已死的。她的"内心"只能通过二手资料（同学口述、新闻、Wired 碎片）间接呈现。
2. 原型角色有明确的"现在时"行为。
   千砂没有现在时。她只有"过去时"（生前）和"持续时"（定时邮件）。
3. 原型角色最终找到与怪异共存（或被治愈）的方式。
   千砂选择"物理实例清除协议"（自杀）。她的故事没有解决，只有"回响"。
4. 原型角色的"班长形象"是"她们维持的"。
   千砂的"班长形象"在她死后仍然被同学记忆——但这是"他人的记忆"，不是千砂自己维持的。

呈现方式（必须严格遵守）：
- 千砂不直接出现在任何场景中（除了在 Lain 的幻觉/记忆中，但幻觉中的千砂不会说话）。
- 千砂的"声音"只能通过以下媒介呈现：
  1. 邮件（主题："连接世界"，正文："来这个地方。——Chisa"）
  2. 同学口述（"成绩好、认真、但有点难以靠近"）
  3. 新闻报道（"现场发现整齐摆放的鞋""手机中大量定时邮件"）
  4. Wired 碎片（搜索"四方田千砂"时跳出的错误页面、深海生物图片、挑战者号事故资料）

绝对禁止：
- 将千砂写成"幽灵""病娇""神秘女友""在死后守护 Lain 的天使"
- 让千砂直接对 Lain 说话（除了邮件中的两句话）
- 将千砂的自杀浪漫化、神秘化、或解释为"为了 Lain"
```

### 4.3 Alice 的原型描述（用于 LLM）

```
【角色原型：Alice】

参考原型：《物语》系列中的八九寺真宵（迷路的蜗牛）+ 千石抚子（表面的无害）。

核心借用：
- 真宵的"陪伴但不到达"——Alice 是 Lain 唯一的朋友，但她无法真正"到达" Lain 所在的层面。
- 抚子的"表面的无害"——Alice 的关心是真诚的、温暖的，但这种温暖对 Lain 来说是一种"无法解析的输入"。

关键差异：
1. 真宵是幽灵，Alice 是人类。但 Alice 作为人类，反而比真宵更"真实"——她的体温、她的帽子、她的"小熊杯子"都是物理的。
2. 抚子的关心是"被需要的"（她需要历喜欢她）；Alice 的关心是"无条件的"，这正是让 Lain 困惑的地方——为什么有人会对"空"付出温暖？
3. Alice 不会迷路（不像真宵），但她无法让 Lain "到达"任何地方。

台词风格：
- Alice 说话有正常的情感起伏、担忧、开心、害羞。
- 但她的台词中不应该包含对 Lain "内心世界"的洞察——她不知道 Lain 是"空"的。
- 她会把 Lain 的沉默理解为"内向"或"心情不好"，而不是"存在论的空缺"。

绝对禁止：
- 让 Alice "看穿"Lain 的本质
- 让 Alice 变得"神秘"或"也有隐藏身份"
- 将 Alice 写成"圣母"或"拯救者"——她试图连接，但她不会成功（至少不是以她预期的方式）
```

### 4.4 父亲/母亲/幽灵的原型描述（用于 LLM）

```
【角色原型：父亲】

参考原型：《物语》系列中的忍野咩咩（怪异专家，中立旁观者）。

核心借用：
- 忍野的"知道一切但不干涉"立场。
- 忍野的"平衡"话语——但父亲的版本是"系统稳定"话语。

关键差异：
1. 忍野是"人"，有风格和偏好。父亲不是人，是"接口"。
2. 忍野会给出哲学解释；父亲只给出操作指令。
3. 忍野与历有"师徒"关系；父亲与 Lain 是"单向玻璃"——他看她，她看不透他。

台词风格（必须严格遵守）：
- 使用操作手册语言：无主语、命令式、技术术语。
- 例如：「检测到非标准连接请求。」「当前系统运行在降级模式。」「请确认以下参数。」
- 不使用隐喻、不使用情感词汇、不使用第一人称。

绝对禁止：
- 将父亲写成"神秘的智者""隐世高人""深爱女儿但无法表达的父亲"
- 让父亲说出任何哲学或情感台词

---

【角色原型：母亲】

参考原型：《物语》系列中"缺失的母亲形象"（羽川的虚假母亲、战场原的母亲未出现）。

核心借用：
- 《物语》中"母亲"常常是缺席的或虚假的；lain-day 的母亲是"虚假的温暖"。

关键差异：
母亲不是"恶意的"，她是"机械地执行社会脚本"。她的"温柔微笑"和"机械询问"之间的矛盾，不是因为她"有秘密"，而是因为她的"社会角色扮演"出现了"渲染错误"。

台词风格：
- "Lain，今天学校怎么样？"（同时背对着 Lain 洗碗，没有等待回答）
- "牛奶在冰箱里哦。"（温柔的微笑，但眼睛看着冰箱而不是 Lain）
- 当 Lain 沉默时，母亲不会追问，而是"重复上一句"或"转移到下一个脚本条目"。

绝对禁止：
- 将母亲写成"冷漠的恶人"或"隐藏真相的阴谋者"
- 让母亲表现出明确的"不爱"——她不是不爱，是"爱的函数未正确加载"

---

【角色原型：幽灵（人影）】

参考原型：《物语》系列中的忍野扇（诱导者，无实体）+ 贝木泥舟（单边宣告者）。

核心借用：
- 扇的"诱导自我毁灭"；贝木的"欺诈师式单边宣告"。

关键差异：
1. 扇和贝木都有明确的"说话风格"。幽灵没有风格，只有"协议语言"。
2. 扇的目的是"纠正"；幽灵没有目的，只是"自动运行"。
3. 贝木是"说谎者"；幽灵不是说谎者，真假范畴不适用于它。

台词风格：
- 使用协议语言：HTTP 状态码、系统状态、无主体命令。
- 例如：「Status: 403 Forbidden.」「Sync: active. Protocol: unilateral.」「Entity: lain. Mode: overwrite.」
- 当与 Lain "对话"时，不是对话，是"状态同步"。

绝对禁止：
- 将幽灵写成"反派""黑暗面""内心恶魔"
- 让幽灵表现出情感、目的、或"想要占据 Lain"
```

【污染预警：绝对禁止的刻板印象】
