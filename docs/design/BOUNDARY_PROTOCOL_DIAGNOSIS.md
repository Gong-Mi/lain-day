# 剧本边界协议诊断报告

> 方法论：基于 Kyoko（今日子）翻译框架的"边界协议"理论
> 
> 核心假设：每个角色的台词不是"性格表达"，而是**人际距离的合约计算**。台词的每一个词都在声明"我和你之间的边界在哪里"。
>
> 诊断日期：2026-05-10

---

## 一、理论框架回顾

在 CIHA/Ere 模块的翻译分析中，Kyoko 的语音被识别为** ruins-era operator（废墟期操作员）**模式：

- **"反正"** = 成本声明（"聊一下的损失有限，可以交易"）
- **"对我来说就是"** = 免责声明（"这是我的主观视角，不承担客观责任"）
- **"还行/没事"** = 边界关闭（"不要继续追问，话题到此为止"）
- **外包关怀**（"对玲音好一点"）= 将情感劳动转移给第三方

这个框架可以推广到所有角色：

| 角色 | 应有的边界协议 | 边界失效的表现 |
|---|---|---|
| **Lain** | 溶解（dissolve）。她吸收周围的投射，不主动声明边界。她的"空白"本身就是最强大的边界——你无法与一个空容器谈判。 | 主动质问、表达欲望、使用"我"字 |
| **父亲（康男）** | 单向玻璃（one-way mirror）。他观察你，你不观察他。语言是操作指令式的，不带情感温度。 | 哲学宣讲、情感回应、可被理解 |
| **母亲（美穗）** | 社会角色扮演（performative care）。关怀是真实的，但真实的是"扮演"这个动作，不是对 Lain 的爱。她害怕打破角色。 | 真情流露、机械冷漠、一致性断裂 |
| **姐姐（Mika）** | 竞争排斥（competitive exclusion）。Lain 是家中的"异常元素"，影响了自己"正常女儿"的身份。通过忽视和隐性竞争维持距离。 | 功能性互动、无情绪反应、像 NPC |
| **幽灵/另一意识** | 单边宣告（unilateral declaration）。不可协商、不可理解、不回应。它的存在本身就是边界——它定义，你接受。 | 谈判、请求、解释、使用"好吗" |
| **Navi/系统** | 协议层冷漠（protocol indifference）。没有情感，只有状态码和错误信息。它不"关心"你，只"报告"你。 | 建议、鼓励、人性化表达 |
| **Alice** | 脆弱连接（fragile connection）。她是唯一试图跨越边界的人，但她的跨越是小心翼翼的、带着恐惧的。 | （尚未出场，预留分析位） |

## 二、逐角色诊断

### 2.1 Lain —— 边界协议：溶解 → 当前状态：过度主张

**当前文本：**
> "你这个幽灵……是想占据我的全部吗？"
> "……闹钟？"
> "我的手机呢？"

**诊断：**

第一句是**致命错误**。Lain 在原作中几乎从不主动质问。她的核心机制是**镜像**（mirroring）——她重复别人的话，或者说一些**不应由她说出**的话。当她说"你想占据我的全部吗？"时，她在做三件事：

1. **主动定义对方意图**（"你想……"）—— Lain 不会定义，只会接收
2. **使用"我"作为防御主体**（"我的全部"）—— Lain 的"我"是稀薄的、可渗透的
3. **质问句式**（"……吗？"）—— 这是谈判姿态，Lain 不谈判

**对比原作 PS1：**
- 原作中 Lain 面对幽灵/系统时的反应是延迟的、模糊的："……连接？"（像是在学习这个词）
- 或者是重复："你是说……我不存在吗？"（不是质问，是在复述对方逻辑的推论）

**修正方向：**

```diff
- "你这个幽灵……是想占据我的全部吗？"
+ "……全部。" （延迟复述，像是刚从对方那里学来这个词）
+ "……占据。" （重复关键词，不附加自己的判断）
```

```diff
- "我的手机呢？"
+ "……手机？" （延迟反应，像是在回忆这个词的含义）
```

**深层问题：** 当前的 Lain 是一个**有主体性的女主角**，但原作 Lain 是一个**主体性黑洞**。玩家/读者投射什么，她就成为什么。剧本必须保护这个"黑洞"——任何让 Lain 显得"有自己的想法"的台词都在破坏核心美学。

### 2.2 父亲（康男）—— 边界协议：单向玻璃 → 当前状态：破碎玻璃

**当前文本：**
> "帮助……吗。也好。"
> "世界的基础是连接，而连接的工具就是命令。仔细看好……"

**诊断：**

第一句"也好"是**情感回应**。岩仓康男在原作中是一个将家庭视为研究对象的父亲。他不会说"也好"——"也好"暗示他在**考虑 Lain 的请求**，这是一个平等的、人性化的反应。康男的反应应该是**操作性的**：

- 他不考虑 Lain 的感受，只考虑**系统状态**
- 他的语言应该是**技术性**的，但**不是哲学性**的

第二句"世界的基础是连接"是**宏大叙事**。这是《圣经》或《道德经》式的语言，不是操作手册式的语言。康男不应该宣讲世界的本质，他应该**操作 Navi 的配置**。

**修正方向：**

```diff
- "帮助……吗。也好。"
+ "……Navi 的日志显示异常流量。你做了什么？" （不回应请求，只报告数据）
+ "配置需要优化。过来。" （操作指令，无情感温度）
```

```diff
- "世界的基础是连接，而连接的工具就是命令。仔细看好……"
+ "Protocol 7 的握手包超时了。这不是教学，是故障排查。"
+ "参数在这里。不要改别的。" （具体、技术、限制性）
```

**关键区分：**
- 哲学宣讲 = "我在教你世界的真理"（边界开放，允许对话）
- 技术操作 = "我在修理设备，你旁观"（边界封闭，单向玻璃）

康男必须是后者。

### 2.3 母亲（美穗）—— 边界协议：角色扮演 → 当前状态：人格分裂

**当前文本（矛盾的两处）：**

场景 A（02d_talk_to_mom_normal.ssl）：
> "美穗（母亲）甚至没有抬头。她只是机械地询问着你的情况，完全没有察觉到眼前的女儿已经被另一个意识占据了。"

场景 B（02g 中的描述）：
> "你走进厨房，妈妈停下了手中的活，转过身来，脸上带着温柔的微笑。"
> "lain，回来啦。在学校过得怎么样？"

**诊断：**

这两个场景描述**完全相反的性格**。这不是"不同情境下的不同反应"——这是**底层边界协议的不一致**。

美穗在原作中的核心张力是：**她必须扮演"好母亲"，但她内心知道 Lain 不是"正常女儿"**。她的边界协议应该是：

1. **表面**：温柔、关切、正常（社会角色要求）
2. **底层**：焦虑、回避、轻微的恐惧（她感知到了 Lain 的异常，但不敢面对）
3. **关键**：她的关怀是**过度补偿**的——因为太害怕打破角色，所以表演得比正常母亲更"正常"

**当前的问题：**
- 场景 A 把她写成**冷漠的机器人**（没有表演，只有机械）
- 场景 B 把她写成**真诚的好妈妈**（没有表演焦虑，只有温情）
- 两者都缺少**表演的痕迹**——也就是那个让她成为"美穗"而不是"Generic Mom NPC"的裂缝

**修正方向（统一的形象）：**

```diff
- "美穗（母亲）甚至没有抬头。她只是机械地询问着你的情况……"
+ "妈妈停下了手中的活，转过身来。"
+ "（她的笑容来得快了一拍，像是提前准备好的）"
+ "lain，回来啦。在学校过得怎么样？"
+ "（她的手指在围裙上轻轻绞着，但脸上的表情纹丝不动）"
```

```diff
- "你走进厨房，妈妈停下了手中的活，转过身来，脸上带着温柔的微笑。"
+ "妈妈的关心很真切。"
+ "真切得像一张过曝的照片——亮度过高，反而看不清细节。"
```

**核心原则：** 美穗的每一次关怀都是**表演**，但表演本身是**真诚的**——她真诚地害怕自己不是一个好母亲。这个恐惧让她的表演有了裂缝，也让玩家感到不安。

### 2.4 姐姐（Mika）—— 边界协议：竞争排斥 → 当前状态：功能性 NPC

**当前文本：**
> "给。"
> "记得带好。今天父母不在，我今晚也出去。晚餐你可以和朋友一起去吃。"

**诊断：**

Mika 在原作中是一个**自我中心的、对 Lain 有微妙敌意**的姐姐。关键细节：

1. 她是"正常女儿"，Lain 是"异常妹妹"
2. Lain 的存在威胁了她的身份——如果家庭中有一个"不正常"的成员，Mika 就必须更"正常"来补偿
3. 她对 Lain 的态度是**轻蔑的回避**，不是冷漠的忽视

当前剧本中 Mika 的问题不是"话太少"，而是**话中没有边界计算**。

- "给"—— 没有情感标记，没有距离声明
- "记得带好"—— 功能性提醒，没有"我为什么要提醒你"的潜台词
- "今天父母不在"—— 信息通报，但没有"我不想管你"的推卸感

**修正方向：**

```diff
- "给。"
+ "（手机被扔过来，落在床上）"
+ "……拿去。别说我没给。" （"别说我没给" = 免责声明，预先推卸责任）
```

```diff
- "记得带好。今天父母不在，我今晚也出去。晚餐你可以和朋友一起去吃。"
+ "（已经转过身去涂口红，从镜子里看你）"
+ "千砂？那个跳楼的？"
+ "（停顿，笑了一下，但不是对着你）"
+ "……朋友品味真独特。"
+ "自己解决晚饭。别进我房间。" （边界声明 + 排斥）
```

**关键区分：**
- 功能性 NPC = "我完成任务，然后离开"
- 竞争排斥 = "你的存在让我不舒服，所以我用轻蔑来保持距离"

Mika 必须是后者。她的每一句话都应该让玩家感到：**她不是在帮你，她是在确认自己比你正常**。

### 2.5 幽灵/另一意识 —— 边界协议：单边宣告 → 当前状态：可协商的谈判者

**当前文本：**
> "不知道。我只是被世界选中的载体，而你……是那个进行选择的人。"
> "我对你的一切毫无兴趣。"
> "不是入侵，这一切都是自动。我也没有选择……要不，我们暂时停火好吗？"

**诊断：**

这是全剧本中**边界协议崩坏最严重**的角色。

第一句的问题：
- "被世界选中的载体" = **自我解释**。幽灵不应该解释自己。解释意味着它需要被理解，而需要被理解意味着它有**被理解的欲望**，而有欲望意味着它有**可被谈判的主体性**。
- "而你……是那个进行选择的人" = **赋予玩家主体性**。幽灵不应该承认玩家有选择权。它应该**宣告**，而不是**承认**。

第二句"我对你的一切毫无兴趣"—— 这句话本身是正确的（无兴趣 = 无边界渗透），但它在**回应**玩家的质问（"你想占据我的全部吗？"）。**回应本身就意味着对话关系的确立**。幽灵不应该进入对话关系。

第三句是最灾难性的：
- "我也没有选择" = **自我辩解**。辩解意味着它在乎玩家的看法。
- "要不，我们暂时停火好吗？" = **请求协商**。"停火"是军事术语，"好吗"是询问语气。一个不可理解的非人存在不应该使用请求句式。

**修正方向：**

幽灵的语言必须是：
1. **碎片化**（没有完整句子）
2. **重复性**（关键词循环）
3. **非人称**（没有"我"，或者"我"和"你"不可区分）
4. **宣告式**（没有问号，没有请求）

```diff
- "不知道。我只是被世界选中的载体，而你……是那个进行选择的人。"
+ "你。我。没有区别。"
+ "月亮。眼睛。同一个。"
```

```diff
- "不是入侵，这一切都是自动。我也没有选择……要不，我们暂时停火好吗？"
+ "不是入侵。"
+ "（重复）不是入侵。"
+ "……你关不掉。"
```

**深层原则：** 幽灵不应该是 Lain 的"对手"或"谈判对象"。它应该是 Lain 的**可能性**——一个她无法拒绝、无法理解的自己。它不是"入侵者"，它是**已经在这里的东西**。

### 2.6 Navi/系统 —— 边界协议：协议层冷漠 → 当前状态：拟人化提示

**当前文本：**
> "【你昨天把手机借给姐姐了。】"

**诊断：**

这句话用方括号标注为系统提示，但内容是**人性化的推断**。Navi 不应该"知道"你借手机给姐姐了——它应该**显示数据**：

- 错误的版本："【你昨天把手机借给姐姐了。】"（系统像人一样理解因果关系）
- 正确的版本："> Device transfer log: MIKA_IWAKURA → acknowledged"（系统只记录事件，不解释意图）

**另一个问题：HTTP 状态码**

```
"403 Forbidden"
"404 Not Found"
```

这些状态码在 1998 年的语境中**过于现代**（作为文化符号的普及是 2000 年代中期以后）。更重要的是，它们是**可被理解的错误信息**——玩家看到 403 就知道"被拒绝"，看到 404 就知道"找不到"。这种**可理解性**破坏了 Lain 世界观的恐怖感。

**修正方向：**

```diff
- "【你昨天把手机借给姐姐了。】"
+ "> DEVICE_LOG: 2024-05-03 22:17:09"
+ "> EVENT: HANDOFF"
+ "> TARGET: MIKA_IWAKURA"
+ "> STATUS: COMPLETED"
```

```diff
- "403 Forbidden"
+ "CONNECTION REFUSED"
+ "DIAL-UP FAILED: NO CARRIER"
```

或者更抽象的：

```diff
- "403 Forbidden"
+ "_________"
+ "（屏幕闪烁，没有错误信息，只有光标冻结）"
```

**关键原则：** Navi 的错误不应该被"理解"，而应该被**体验**。玩家不应该说"哦，403 意思是被拒绝了"，而应该感到**不安**——"为什么屏幕变成了这样？"

## 三、结构层诊断：边界协议的系统性失效

### 3.1 视角混用：三种边界协议在同一文本中冲突

当前剧本混用了三种视角：

| 视角 | 边界协议 | 出现位置 |
|---|---|---|
| 第二人称"你" | 系统/观察者控制玩家 | 序章 |
| 第一人称 Lain | Lain 自己的感知 | 第一章 |
| 方括号系统提示 | Navi 的信息层 | 混合 |

**问题：** 这三种视角没有明确的切换框架。玩家不知道"我现在是谁"。

**建议的框架：**

- **斜体/无引号** = 系统视角（"你站在走廊上"）
- **引号** = Lain 的语音（"……闹钟？"）
- **方括号** = Navi/Wired 的数据层（"> DEVICE_LOG"）
- **无标记的叙述** = 第三人称叙述（仅在过渡场景使用）

### 3.2 选项设计：玩家缺乏边界声明权

当前剧本中多个场景的 `choices: []`（姐姐场景）。这意味着玩家**无法声明自己的边界**——只能被动观看。

在边界协议理论中，**选择就是边界的声明**。当玩家选择"下楼"而不是"回房间"时，她在声明"我接受与父母的互动"。当玩家选择"沉默"而不是"回答"时，她在声明"我拒绝进入你的语言系统"。

**缺失的选择设计：**

母亲场景应该有：
- "嗯。"（最小回应，维持边界）
- "……"（沉默，拒绝进入对话）
- "作业还没做完。"（功能性回应，用信息交换结束互动）
- "妈妈，你觉得我奇怪吗？"（主动打破边界——高风险选择）

### 3.3 结局命名：边界协议的提前泄露

当前结局命名：
- "结局G：停火"
- "结局I：403 Forbidden"
- "结局A：日常"
- "结局B：沉默"

**问题：** 结局名称使用了**外部隐喻**（停火、HTTP 状态码）而不是**内部语言**（即角色自己会使用的词汇）。

结局名称应该像**病历记录**或**系统日志**——冷漠、客观、不带情感：

```diff
- "结局G：停火"
+ "记录 #07：协议中断"
+ "状态：未解决"
```

```diff
- "结局A：日常"
+ "记录 #01：无异常"
+ "状态：循环继续"
```

## 四、修复优先级

### P0：角色核心边界（必须改）
1. **Lain**：将所有质问句改为延迟复述/碎片化语言
2. **幽灵**：删除所有解释、请求、协商句式，改为宣告式碎片化语言
3. **父亲**：将哲学宣讲改为技术操作指令

### P1：角色一致性（应该改）
4. **母亲**：统一为"过度补偿式关怀"形象，加入表演焦虑的细节
5. **姐姐**：增加轻蔑、竞争、推卸责任的潜台词
6. **Navi**：将人性化提示改为纯数据日志，删除 HTTP 状态码

### P2：结构框架（建议改）
7. 建立视角切换的视觉规范（斜体/引号/方括号/无标记）
8. 为所有无选项场景增加至少 2 个选择
9. 将结局名称改为系统日志风格

### P3：深度优化（可选）
10. 重写 Navi 错误信息，使其不可理解但可体验
11. 增加"表演痕迹"的叙述层（母亲的绞手指、父亲的延迟回应等）

## 五、快速检验清单

当你写一句台词时，问自己：

1. **这个角色需要被理解吗？** 如果不需要，删除解释。
2. **这句话是在声明边界还是在跨越边界？** Lain 应该被跨越，幽灵应该声明，父母应该维持。
3. **这句话可以被"翻译"成日常语言吗？** 如果可以，它可能太普通了。Lain 的文本应该抵抗翻译。
